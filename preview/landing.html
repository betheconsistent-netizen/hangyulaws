왜 SubValue인가요?

감이 아닌 데이터로, 내 구독 포트폴리오를 분석합니다.

📊
Value Score
사용 강도·일관성·비용 효율·기능 고유성 등 7가지 항목으로 구독 가치를 0~100점으로 수치화합니다.
📡
사용량 추적
실제 사용 시간을 측정해 "얼마나 쓰는지"를 정확히 파악합니다. 추측이 아니라 실측 기반입니다.
🗓️
결제 캘린더
이번 달 결제 일정을 한눈에 확인하세요. 갑작스러운 결제에 당황하지 않도록 미리 알려드립니다.
🔔
스마트 알림
결제 3일 전, 가격 인상 공지, 절감 기회를 적시에 알려드립니다. 알림 스팸은 없습니다.
🔍
기능 중복 감지
ChatGPT와 Claude처럼 비슷한 기능을 가진 서비스를 자동으로 감지하고, 28일 관찰 후 결론을 냅니다.
💡
포트폴리오 최적화
전체 구독을 한 화면에서 분석하고, 해지·다운그레이드·유지 추천과 예상 절감액을 제시합니다.

정직한 분석을 약속합니다

SubValue는 추천의 근거를 숨기지 않습니다.

✓
측정 안 된 사용량은 0으로 처리하지 않습니다 데이터 없으면 "판단 보류" — 근거 없는 해지 추천을 하지 않습니다.
✓
미확인 정보로 알림을 보내지 않습니다 자동 감지된 가격 변경은 "확인 필요" 배지로만 표시합니다.
✓
"때문에"라는 표현을 쓰지 않습니다 인과가 아닌 관측으로만 서술합니다. 결정은 사용자의 몫입니다.
✓
제휴 추천이 없습니다 제휴 관계가 있는 경우 반드시 공시합니다. 현재는 제휴 없음.
